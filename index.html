OULY Documentation

OULY (Optimized Utility Library) is a C++20 library for programs where allocation patterns, cache behaviour and thread wake-ups matter: game engines, simulations, tools and services. It provides task schedulers, memory allocators, cache-friendly containers, an entity component system, and reflection-driven serialization, behind small STL-like interfaces that can be adopted one header at a time.

Modules

Task scheduling (ouly/scheduler/)

Three work-stealing scheduler generations behind one API, value tasks with continuations, structured task scopes, parallel_for and auto_parallel_for, lazily started coroutines, and static and dynamic flow graphs.

Memory allocators (ouly/allocators/)

Linear, arena, stack and pool allocators, thread-safe frame allocators, virtual memory, memory-mapped files, and coalescing offset suballocators for GPU-style heaps with defragmentation.

Containers (ouly/containers/)

Small and structure-of-arrays vectors, sparse vectors and tables, block vectors, an intrusive list, single-threaded and concurrent queues, and a heterogeneous blackboard.

Entity component system (ouly/ecs/)

Registries with optional revision tracking, component storages with selectable layouts, collections and sparse-to-dense maps.

Serialization and reflection (ouly/serializers/, ouly/reflection/)

Compile-time reflection that drives binary, YAML and user-defined structured formats.

Utilities and DSL (ouly/utility/, ouly/dsl/)

Delegates, program arguments, views, intrusive pointers, hashing, string helpers, a macro expression evaluator and an event-driven YAML parser.
