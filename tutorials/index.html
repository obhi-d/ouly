Overview

  1. Task Scheduler Tutorial: workgroups and task contexts, the v1/v2/v3 scheduler generations, value tasks, task scopes, parallel loops, coroutines and flow graphs.

  2. Memory Management Tutorial: linear, stack and pool allocators, thread-safe frame allocators, memory-mapped files, and the coalescing offset allocators with defragmentation.

  3. Containers Tutorial: small_vector, soavector, sparse storage, intrusive lists, queues and the blackboard.

  4. Entity Component System Tutorial: registries, component storages, collections and sparse-to-dense maps.

  5. Serialization Tutorial: reflection, binary streams, YAML and custom formats.

  6. Utilities and DSL Tutorial: program arguments, delegates, macro expressions, the YAML event parser, views, pointers and hashing.

The unit tests in unit_tests/ are the most complete source of further examples; see Examples.
